# 较大候选图的匹配与证据一致性

## 目标与边界

3×3 之外，当前匹配是否仍取得最大完成数，并为每项动作保留准确且不复用的执行证据？

时间盒：40 分钟。本轮先观察，不自动修复实现。输入、随机种子、版本、断言和异常原文全部保存；失败、超时与未完成分开记，不把缺少复现写成安全证明。

## 规模与输入

固定随机种子 61012。随机图规模 4、8、12，每档稀疏/中等/稠密三种密度，各 20 个图。生成参数资格关系而不是直接调用匹配内部实现。

独立 oracle 用子集动态规划计算最大完成数，不复用生产增广路径算法。比较 cardinality 与 GO/NO_GO；存在多个合法分配时不要求与 oracle 返回相同 witness。

再构造规模 64、256 的已知答案图：长交替路径、稠密完美匹配、孤立动作、多个动作争夺同一调用的瓶颈图。已知答案由构造或可说明的上界/下界确定，不拿旧实现充当权威。每类采用三种固定声明/执行排列。

## 必须核对的结果

- 每项 matches 对应真实工具名、参数与符合条件的结果，callSeq/resultSeq及sourceEventSeqs准确。
- 单次执行不复用，允许文本 ID 重复；所有动作恰好出现在 matches 或 missing 中。
- 混合 tool-completed/result-equals，加入错误、缺失与不符合结果，核对它们不能提供成功结果证据。
- 同一输入重复输出一致；排列改变时完成数量和最终 GO/NO_GO 不变，不强求等价动作归属不变。
- 核验截止前后、声明前后插入同类事件，确认窗口外执行不会增添资格。

每个 oracle 子进程最多 5 秒，大图每例最多 10 秒。超时是测试未完成或性能观察，不等价于算法错误；不为了时间盒改为以生产算法验生产算法。

## 产物

可复现种子、图构造、独立 oracle、失败时完整最小输入和 witness 对照。证据目录 `artifacts/backend-rebuild/large-matching-spike/`。

## 完成条件

每个计划用例都有输入、实际结果和证据路径；未执行项明确标记。结论区分已复现、当前边界、未复现与仍待决策。达到时间盒即汇总，不通过扩大场景追求全面证明。

## 研究结果与决策

2026-10-12 已执行，未修改生产实现。固定 seed 61012，Node v24.12.0；核验源码 SHA-256 为 `15efd0d33918294b3b4de653b3671eaac3f1497463a1662d59785b81e25704e0`。

### 观察结果

- 随机图 180 例：4/8/12 各 60 例，三个密度各 20 例；其中 90 例混合完成断言与字段断言，并注入失败、缺失结果和字段不符合。用独立子集 DP 求最大完成数。
- 构造图 8 例：64/256 各包含长交替路径、稠密完美图、孤立动作、瓶颈竞争四类。长路径有显式完美分配；孤立图有 n−1 上界和对角分配下界；瓶颈图有 3n/4 的可说明上下界。
- 每例三组固定声明/执行排列，每组核验两遍确认确定性。排列不要求 witness 相同，只要求 cardinality 和 GO/NO_GO 不变。
- 全部工具调用使用相同文本 ID，以事件序号逐项核对 witness：准确工具名、参数资格、结果字段、callSeq/resultSeq/sourceEventSeqs、唯一执行及完整动作分区。
- 每例插入声明前和截止后的同类已完成调用；另加 1 例明确负例：唯一窗口内调用没有结果，窗口外同类成功执行不能补足。
- **189/189 例通过；567 个排列场景、每场景两次核验，无失败、超时、取消或跳过。** 本次进程总时长约 6.45 秒只作执行记录，不能当作性能收益数据。

每个随机图子进程有 5 秒终止界限，大图有 10 秒界限；超时会作为独立状态保存，而不是误报成算法不正确。完整失败输入机制已具备，本轮没有失败输入可进一步缩减。

### 结论与边界

在这些图及排列上，未发现最大匹配、执行去重、witness 归属或窗口资格的新缺陷；原有仅 3×3 穷举的证据已经扩展到随机 12×12 与构造 256×256。当前无新增修复建议。

本实验使用原生事件形状的人工构造数据，**没有重新验证 DSH 运行时可达性**。随机图不是全图穷举；大图只有四类已知答案构造，未证明任意规模或任意图的全面正确性。三组排列也不是全部排列。端到端长期资源成本由另一组实验承担，本组不作性能优化结论。
