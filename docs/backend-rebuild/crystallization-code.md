# 实际结晶代码闭环验证

## 接入与复用

本次把之前实验的 Workspace、Registry、快照与隔离执行逻辑移入后台代码适配器，沿用既有 hash 绑定，没有另建版本治理机制。`crystallization.code` 配置资产目录、Python 路径和阶段超时即可连接独立 DSH 评估 agent 的注册工具及实际执行。DSH 继续负责模型、工具、agent loop 和会话。

生成的 validate/guard/execute/check 都是实际 Python 文件，经子进程运行。材料绑定文件摘要和命令，注册验证通过不等于准入；历史对拍通过才接管，异常回到原路径并重新评估。执行结果、退出码、超时、输出及阶段耗时保留实际收据。

## 验证结果

| 层次 | 观察 |
| --- | --- |
| 执行器 | 10项，实际文件/进程：异常退出、无输出、非法或过大JSON、check失败、超时、验证失败、hash或命令变化、越界写入、重建服务恢复 |
| 原生 DSH | 新增3项：自动发现/生成/对拍/接管/guard回退/恢复；check失败后原路径及新版重验；快照修改及验证失败不得接管 |
| 相关回归 | 41/41，通过；code-all-focused.log |
| 全仓回归 | 609/609，通过；code-full-tests.log |
| 真实模型 | gpt-6-astra high，两个独立评估会话均 promoted；七批结果外部验收通过 |

真实模型实验的任务是整数数组的去重升序及含重复项求和，有公开明确的契约。业务驱动使用确定性 DSH LlmAdapter，原工具是已知结果实现；没有预填候选文件或候选 run 函数。候选源码由真实模型经注册工具提交。

| 批次 | 实际路径与结果 |
| --- | --- |
| 1、2 | 原工具，积累两个不同输入，触发独立评估 |
| 3、4、5 | 模型生成 Python 快照实际接管，外部验收通过；4为空数组 |

第一轮评估的首次注册命令不符合接口，模型收到工具错误后自行修正。第二轮评估生成 version 2，并重新对拍两个历史原结果；旧快路径结果未充当独立原路径依据。

## 证据边界

这是一个已知结果的有限边界机制实验，证明实际代码接入、异常回退、重新准入和正常关闭后恢复。业务侧仍为确定性驱动，不代表全程自主业务开发。没有证明通用任务正确性、长期成功率、任意进程崩溃窗口或成本收益。当前适配器仅支持 macOS sandbox-exec 与本地 Python JSON 文件协议；注册目录按单写者使用，隔离脚本目前不能访问网络。简单数组计算的原实现比启动 Python 快，故不将本次接管声称为性能优化。
