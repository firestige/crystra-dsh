# 首批项目共识（待用户批准）

范围：/Users/firestige/Projects/crystra-backend-rebuild；scope：crystra-backend-rebuild。

1. Crystra 是 DSH 后台能力插件，DSH 保持 agent 调度、模型调用、工具执行和会话管理的所有权。当前不开发工作台、JSONIR、远端服务或新的 harness。
2. 共识管理保障身份、效力、版本、范围及操作可靠性，不保证共识正文正确；内容由用户和 agent 判断。
3. Barrier 核验事先声明的可检查承诺是否实际兑现，结果只有 GO / NO_GO。它不是 reviewer，不承诺拦截所有幻觉或设计错误。修订承诺必须有理由，并保留未完成责任和可追溯依据。
4. 反思独立检查核心代码的正确性、鲁棒性和性能，以实际源码、测试及实验为依据，与 Barrier 分开。
5. 结晶由机制发现重复执行并推动独立评估；agent 可以接受、拒绝或推迟。候选经适用条件、代码 hash 和独立历史对拍验证后才接管局部调用；失效或异常回退原执行路径。
6. MVP 聚焦这些核心问题，采用单机部署和本地服务；不增加多租户、防篡改或隐私加密等企业特性。不承诺 exactly-once、任意崩溃窗口恢复或任意任务的正确性。
7. 必须区分已验证事实、未复现推测和未覆盖边界；不能只凭 agent 自报、happy path 或进程成功退出就宣布能力通过。
