## 未证明的边界

完整 Crystra plugin turn-stopping hook 对异常的最终表现尚未跑；已确认的是公共Controller和真实DSH原生执行、journal/session持久恢复路径。深度精确阈值未二分定位，4096不是跨平台安全上限。任意匹配图、全部故障窗口、真实长程host内存与多小时稳定性没有被本轮有限输入证明。

当前需要工程处理的是无法安全比较的候选使整个检查抛错；当前需要策略选择的是等价最大分配下的拆分许可。二者不混为一项。其余项目已有有界观察结论，不因无法证明任意情况而持续扩大实验。

后续两项已修复：异常比较受控拒绝并支持正常后继闭合，等价拆分允许提议约束的合法最大分配。全仓568项通过。详见 [修复及回归证据](payload-split-fix.md)；上文未修复状态保留为当时实验记录。
