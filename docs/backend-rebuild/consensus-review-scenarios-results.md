# 单页审阅全文场景扩测

以现有 2264 字符长修改稿为基线，每个场景保留完整文档。新增八份受控版本，另检查原始首批共识与完整长稿的全部增删片段。合成内容仅用于隔离显示验收，不是正式共识或产品需求。

## 复现的问题与修复

1. 原句段全局对齐在两个长版本间超过 20000 配对上限时，会退化成全文删除/新增。八个新场景最初全部如此，粗略的“两版可还原”断言无法识别；后来加入所有未改段落的 context 断言，明确复现。修复为先匹配完整段落锚点，只对局部修改区域细比；任何局部回退不应污染已匹配的段落。
2. 局部比较恢复后，整段重写仍会因共享“测试及实验”等词被拆碎。对于内部只残留少量共用词、保留比例低于较短版本 60% 的改写区域，整体显示替换。使用较短版本作分母，防止“大量扩写”被错误当成“整体重写”。原始长稿保留原条款的断言验证了这个区别。
3. 分词仍可能留下“性”“的”等单字，拆开完整词组。合并编辑间 1–4 个汉字的短连接片段；替换后紧邻的单汉字分词也保守纳入替换，减少词尾碎片。因此标记范围可能包含两边相同的短连接词，这是可读性取舍，并非该连接词内容真的改变。

## 八个完整文档结果

| 场景 | 检查结果 |
| --- | --- |
| 整段替换，共享测试/模型词汇 | 旧段完整删除、新段完整新增，不用共享词拆开 |
| 段内新增一句 | 只新增完整一句，原有句段不变 |
| 段内删除一句 | 只删除完整一句，邻近句段不变 |
| 跨章节移动段落 | 原处完整删除、目标处完整新增 |
| 少量词语修改 | 鲁棒性→稳定性、尚待验证的怀疑→需要复核的疑点以完整片段呈现 |
| 中英文参数词组 | prepareTimeoutMs→executionTimeoutMs 整体替换标识符 |
| 移动同时改词 | 原段和目标段整体显示，不把原地零散词拼成修改 |
| 全文混合修改 | 同时包含整段替换、句子替换、段落移动及单机→本机改词，逐项完整 |

每个场景验证两版逐字还原、全部实际未改段落保持 context，以及受控修改片段完整性。段落移动未提供“移动”专用标记，显示为完整删增，不还原作者真实编辑操作。对原始首批→长稿另外验证三个完整未改条款仍保留，而不是将整篇扩写涂成替换。九个全文测试加入既有回归后共 388 项通过。

## 实际 DSH 展示

通过隔离的原生审批服务、session projection、侧栏和单页审阅一次展示八份文档，逐个定位变更并保存截图。DOM 对八份文档的旧版/新版还原均精确，预定整段/句子/词组标记均完整。浏览器无错误；左右模式八文档行高一致、行内 mark 为零；拒绝后旧审批面板失效。没有付费模型调用，没有发布合成稿。

实际 Web profile 已通过原生插件机制更新到 approval-r11。原模型、凭据、UI、LAN 配置核对保持完整，认证访问和原生 RPC 正常，未认证访问仍为 401。本次历史 Barrier 记录仅作安装保持性核对，不是新的模型闭环测试。
