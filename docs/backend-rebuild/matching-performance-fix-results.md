# 缺项匹配性能修复与真实 DSH 复验

修复 `src/backend/barrier.js` 中的重复候选构建和重复耗尽搜索。相同完整谓词共享候选行，但每项承诺保留独立身份；单次执行只能匹配一项承诺。直接空位分配与单调游标保持原有首个可用执行顺序；仅在同一次核验中复用已完整搜索证明耗尽的区域，新证据触发全新计算。拆分继续优先满足 retain，使用集合查询避免重复线性扫描。没有新增生产超时或承诺数量限制，也未替换原有最大匹配与责任转移规则。

## 回归

对所有 512 个三乘三候选图、六种声明顺序及每种合法大小的 retain/defer 分区，核对旧分配算法的具体证据和拆分可行性；另补充 300 个确定性随机矩形图、局部耗尽、新证据恢复、长交替重分配链，以及谓词 kind/path/equals 区分。完整后台测试 421 项通过，无失败或跳过。
